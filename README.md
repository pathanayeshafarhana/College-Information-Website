# College Information and Admissions Website

## Aim
To design and develop a college information website using HTML and CSS.

## Introduction
This website provides information about a college, its departments, courses, faculty, admissions and campus facilities.

## Technologies Used
- HTML
- CSS

## Features
1. Home Page
2. About Our College
3. Departments
4. Courses
5. Faculty Information
6. Admissions
7. Campus Facilities
8. Contact Information

## Files Used
- index.html – Contains the website structure and design.
- README.md – Contains project information.

## How to Run
1. Open the index.html file.
2. Run it using a web browser.
3. The college website will appear.

## Conclusion
This project helped me understand the basics of HTML and CSS and learn how to create a simple college website.
